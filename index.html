I am a Ph.D. candidate in Machine Learning at École de Technologie Supérieure (ÉTS) in Montreal, Canada. My research focuses on object detection, vision-language models, test-time and domain adaptation, and video anomaly prediction.

I am currently a visiting Ph.D. researcher at the University of Trento, Italy, where I am developing training-free methods that use multimodal LLMs to predict whether an anomaly will occur in a video and which people will be involved.

During my Ph.D., I proposed the first test-time adaptation method for vision-language object detectors (VLOD-TTA, ECCV 2026) and methods for multi-source domain adaptation in object detection (PMT, WACV 2024; ACIA, WACV 2025). I also worked on object detection from drone footage as a Mitacs Accelerate intern at Ericsson.

selected publications

  1. arXiv
    DESA-TTA: Dynamic EMA and Source Anchoring for Test-Time Adaptation
    Atif Belal, Lilian Hollard, Marco Pedersoli, and Eric Granger
    arXiv preprint arXiv:2609.01795, 2026
    Abs arXiv Bib PDF Code

    Mean-teacher test-time adaptation is sensitive to a fixed EMA rate, and noisy pseudo-labels make the student drift. DESA-TTA picks a per-sample EMA coefficient from the teacher’s uncertainty and pulls the student back toward its pretrained weights in proportion to its drift. It gives consistent gains across distribution shifts and two vision-language detectors, including +14.5 AP50 over zero-shot inference on VOC-C.

  2. ECCV
    VLOD-TTA: Test-Time Adaptation of Vision-Language Object Detectors
    Atif Belal, Heitor R. Medeiros, Marco Pedersoli, and Eric Granger
    In European Conference on Computer Vision (ECCV), 2026
    Abs arXiv Bib PDF Code

    Vision-language object detectors such as YOLO-World and Grounding DINO lose accuracy under distribution shift. VLOD-TTA adapts them at test time with an IoU-weighted entropy loss that favors spatially coherent box clusters, and with image-conditioned prompt selection. It outperforms standard test-time adaptation baselines and the prior state of the art across artistic, adverse driving, low-light and corruption shifts.

  3. ICCV
    Visual Modality Prompt for Adapting Vision-Language Object Detectors
    Heitor R. Medeiros, Atif Belal, Srikanth Muralidharan, Eric Granger, and Marco Pedersoli
    In IEEE/CVF International Conference on Computer Vision (ICCV), 2025
    Abs arXiv Bib HTML Code

    Vision-language detectors such as YOLO-World and Grounding DINO struggle on new visual modalities like infrared and depth. ModPrompt is an encoder-decoder visual prompt with a decoupled residual that adapts them to these modalities without degrading their zero-shot ability. On LLVIP, FLIR and NYUv2, it approaches the performance of full fine-tuning.

  4. WACV
    Attention-Based Class-Conditioned Alignment for Multi-Source Domain Adaptation of Object Detectors
    Atif Belal, Akhil Meethal, Francisco Perdigon Romero, Marco Pedersoli, and Eric Granger
    In IEEE/CVF Winter Conference on Applications of Computer Vision (WACV), 2025
    Abs arXiv Bib PDF Code

    Most multi-source domain adaptation methods for object detection align features without considering object classes, and prototype-based class-wise alignment suffers from noisy pseudo-labels and class imbalance. ACIA uses an attention module with an adversarial domain classifier to learn instance representations that are both domain-invariant and class-specific.

  5. WACV
    Multi-Source Domain Adaptation for Object Detection with Prototype-based Mean Teacher
    Atif Belal, Akhil Meethal, Francisco Perdigon Romero, Marco Pedersoli, and Eric Granger
    In IEEE/CVF Winter Conference on Applications of Computer Vision (WACV), 2024
    Abs arXiv Bib PDF Code

    Multi-source domain adaptation methods for object detection often add a domain-specific subnetwork for each source, so the number of parameters grows with the number of sources. PMT (Prototype-based Mean Teacher) replaces them with class prototypes learned with a contrastive loss, keeping the model compact, and outperforms state-of-the-art methods on several object detection benchmarks.
